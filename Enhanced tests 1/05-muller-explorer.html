How nesting works

A clone's envelope contains its own population plus all descendants. Its own abundance is split around its children, so descendants emerge inside the parent rather than as unrelated stacked bands.

Sibling envelopes never overlap. Linear interpolation between time samples preserves containment; no spline smoothing invents negative populations or boundary crossings.

Export / provenance

All parent links, emergence times, annotations, and population trajectories are invented. Absolute mode uses arbitrary demo population units, not measured cell counts. This is a visual test, not an evolutionary reconstruction.
