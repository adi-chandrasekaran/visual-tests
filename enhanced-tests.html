Saved edits, individual files & preview requirements

Each tab loads its actual HTML file from Enhanced tests 1/—nothing is copied into this launcher. Save edits to an individual file, then use Reload current view to see them here. It resets that view; other loaded tabs keep their selections, camera positions and scroll. Refreshing the whole application resets every tab. This launcher does not automatically watch the filesystem.

Modules load on their first visit and stay mounted afterwards. Background animations can continue in previously visited tabs. JavaScript, internet access for the existing CDN libraries, local HTML frames and WebGL must be allowed by your Cursor HTML preview. No local server or build step is needed. If a preview blocks local frames, use the individual files; the launcher cannot bypass that preview restriction.
